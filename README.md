# Small-Language-Model-from-Scratch
This repository contains the code for my first attempt at programming a Small Language Model from scratch. My goal is to begin with a micro-architecture of one to two million parameters pretrained on the TinyStories dataset [Elden, R. and Li, Yuanzhi, 2023] to generate short stories. This model will contain only one or two transformer blocks. Initially, I intend to program in a notebook run in a Kaggle kernel, using small data samples to test my code and iterate quickly. After a satisfactory run of the program with the entirety of the dataset, I intend to clean-up and rewrite the code as finished product in .py files, with a separation between different components (like train, validate, generate, etc.). This project will serve as a base for other SLM-based projects I work on.
